# 4. Funções

Funções agrupam instruções que podem ser reutilizadas.

```text
function add(a, b) {
    return a + b
}

print(add(2, 3))         # 5
```

- Declare funções no nível principal do arquivo.
- Parâmetros existem apenas dentro da função.
- `return` devolve um valor. Sem `return`, a função devolve `null`.
- Não há funções anônimas nem funções como valor nesta versão.
