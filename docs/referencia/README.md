## Convenções desta documentação

- Código e nomes de funções são escritos em inglês.
- Aliases em português aparecem entre parênteses quando existem, por exemplo `print` (`imprimir`).
- Mensagens de erro citam o código `CBxxx`. Veja [Erros](../ferramentas/erros.md).
